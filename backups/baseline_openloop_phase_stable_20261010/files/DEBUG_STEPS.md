# 分阶段电机验证（保持 TIM1 / ADC / SMO / VOFA 框架）

每项测试先复位，等待 ready=1。当前停止后不支持直接重新启动。
逐条发送命令，不开启 VOFA 自动循环发送。所有旋转测试使用 M0 停止，
等待至少 3 秒完成 POSTZERO，再发送 D0 获取日志。

| 命令 | 测试内容 | 通过后再做 |
|---|---|---|
| A1 | 固定角度、Id=0.3A 电流 PI，自动停止 | O1 |
| O1 | 原开环电压/角度，SMO 仅影子运行，始终不接管 | H1 |
| H1 | 通过锁相检查后融合角度，保持 Vd=0.045、Vq=0，不启用旋转电流 PI | M1 |
| M1 | 相同角度融合，再无阶跃初始化电流 PI，1 秒渐变到 Id=0、Iq=0.25A | 重复验证 |
| M0 | 立即关闭输出，进入三秒后采样 | D0 |
| D0 | 已停止时排空二进制并输出文本，不是停止命令 | 复位 |

O1 先运行至加速结束后约 2 秒，确认真实转子持续转动，再适当延长。
H1、M1 若转子已停止或持续振动，应立即 M0，不要等待估算速度归零。
记录实际停转时刻与 M0 发送时刻，二者不是同一事件。

VOFA 仍为五个 float 加帧尾：Iu、Iv、speed_ratio、theta_open、theta_smo。
没有 stage 通道；不要使用旧启动提示中的 Id/CH5 解释。
速度比例和 SMO 角度都不是实测转速/位置，需通过转子标记或独立测速验证。
调试器 debug_id/debug_iq/debug_Vd/debug_Vq 现在每个有效控制周期更新。

D0 新增 [Test]：mode 1=电流闭环、2=静态、3=纯开环、4=仅角度接管；
stop_stage 是正常停止请求发生的阶段（不是转子失步时刻）。
每阶段的 max_cycles 用于判断时间预算。故障仍使用原有 FaultSnap。
lock 是切换确认计数，达到上限后进入接管阶段便不再更新，不能视为闭环锁定状态。

切换要求：稳态强拖至少 2 秒，连续 1500 拍（约100ms）估算速度在目标±15%，
估算反电势矢量幅值超过0.02V，相位相对该窗口起点漂移不超过0.15rad。
这些是初始工程阈值，不是转子同步的证明；不满足时继续 RUN，需手动 M0。

修正内容：统一 SVPWM/SMO 电压比例0.4330127；角度融合不再同时改变电压幅值；
融合末拍不运行PI；首次PI目标取实测Id/Iq以匹配原输出，再平滑到最终目标。
角度诊断的期望步长使用实际观测器输出角增量及融合补偿变化，避免漏掉PLL比例项。
这项诊断只检查软件角度一致性，不验证观测器物理准确性。

仍需上板验证：V_BUS固定12V、Rs/Ls、电流比例与相序、原有SMO角度+π约定，
以及ADC采样/PWM预装载与观测器电压的时间对齐。当前电压换算为理想指令模型，
不补偿死区/器件压降；当前低调制范围内不触发SVPWM裁剪。
M1是固定转矩电流控制，没有500rpm速度闭环，也没有新增失速检测。

软件验证：

- python3 tests/host/test_handoff_modes.py

主机测试使用实际timer.c及寄存器/理想三角函数模拟；不模拟电机、ADC时序或真实CORDIC。
