## 回退

在项目根目录运行（将 BASE 替换为本目录路径）：

```bash
python3 BASE/restore.py --check
python3 BASE/restore.py --apply
```

--check 校验备份完整性并列出相对基线的修改、缺失及新增文件，不写文件。
--apply 先完整备份当前受管文件到 backups/pre_restore_时间戳/，然后恢复基线文件，并移除受管范围内基线没有的新增文件；被移除内容仍在恢复前备份中。不会改 Git 索引/历史、backups/ 或 .pio/。因此恢复的是磁盘文件，不是 Git 暂存状态。操作前停止编辑器自动保存及构建，避免并发写入。

回退后脚本逐文件校验并检查新增文件。现有 .pio 可能属于其他版本；后续需要烧录时，应先清理并从恢复后的源码重新构建。脚本不会构建、烧录或启动电机。
