# 角度诊断修复与有限幅P对照

本次保持修改前控制参数：500rpm默认、mod=0.058、加速3秒、过流阈值4.0A、SMO滤波200Hz、PLL 90/1500。历史备份不变。
修改前源码位于 backups/before_angle_diag_comparison_20261010/。

每项复位等待 ready，单独发送命令：
- C500：500rpm起动，原0.002 P修正。
- F500：500rpm起动，P=0，纯前馈。
- F450 / F550：450/550rpm起动，P=0；仅在500rpm对照通过后测试。

上述新命令在 CLOSED 采集75000拍（约5秒）后自动关闭MOE，执行原有3秒POSTZERO；之后发送D0。
五秒从CLOSED起算，不从启动命令起算。若未满足原有接管条件，会继续RUN，需M0手动停止。
M0始终可提前停止。每次测试后重新复位。旧M1/O1/H1映射维持当前源码行为，不作为本对照入口。

对比ClosedWindow的电流均值/标准差、估算速度范围、电压均值与限幅次数；同步测实际转速。
不同rpm时speed_ratio分母对应所选测试转速，不恒为500rpm。
统计不证明实际转速或磁链轴正确，单拍锁存仍保留以避免同时改变实验变量。

角度诊断使用当拍和上一拍实际elec_angle，双向处理±pi回绕；CLOSED的期望增量来自上一拍SMO更新的输出角增量（包含PLL比例项及相位补偿变化）。
没有放宽0.00001rad误差阈值。它检查角度传递一致性，不验证估算器物理正确性。

当前源码还存在独立待处理问题：SMO电压输入为Valpha*V_BUS，而SVPWM采用0.4330127比例；本次为隔离诊断/P对照没有改动。不能将当前测试认定为标准无感FOC已验证。
