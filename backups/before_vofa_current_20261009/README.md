# 三相电流 VOFA 临时试验与回退

备份点：2026-10-09，本轮修改前的磁盘内容（包含用户所有已有修改）。
files/ 保存 timer.c、timer.h、usart.c、main.c、handoff.md；before_sha256.json 验证备份，after_sha256.json 标识本轮测试版本。

测试：12V，维持原参数30rpm、调制幅值0.03、标称过流2A。M1/m1 启动持续开环，M0/m0停止；取消原2秒自动结束，其他故障保护保留。故障锁存需复位。
VOFA：串口921600、8N1、JustFloat；CH0=Iu、CH1=Iv、CH2=Iw、CH3=Iu+Iv+Iw，单位标称A。先等初始化完成，再清空接收显示并选JustFloat、整行发送m1。每10个控制周期取样一次，约1500帧/秒；300帧一块DMA发送，所以显示约有0.2秒缓冲延迟。
电流是原始ADC减浮点偏置、除以-34.05，未经零序补偿或低通。串口丢帧时不会覆盖正在发送的缓冲，也不会阻塞控制ISR；丢帧会使按固定采样率显示的时间轴不连续。
M0后发送尾块，二进制模式仍保持。需要文字诊断时，先停机，稍等，切文字显示，再发送D0/d0；排空DMA且USART发送结束才恢复文字，打印丢帧数和停止/故障状态。运行时D0不生效。二进制期间所有printf被屏蔽。

## 回退

先M0停机并断开电机功率电源。在工程根目录执行：

```sh
python3 backups/before_vofa_current_20261009/restore.py --check
python3 backups/before_vofa_current_20261009/restore.py
pio run
```

再下载新构建固件。恢复脚本只还原以上5个文件，不使用git reset，不触碰其他修改；若这些文件有本轮完成后的编辑，会拒绝覆盖，需让助手按差异选择性撤回。备份文件本身也会做校验。
回退后恢复30rpm、2秒试转版本（原版本启动文字误写100rpm也会原样恢复）。源码回退不等于板上固件回退，必须重建并下载。

验证：pio run成功，原有警告保留；主机模拟通过持续运行/计数饱和、DMA缓冲所有权、丢帧背压、发送顺序、停机尾块、JustFloat帧结构、文字切换、重启与过流锁存。不代表已实测串口吞吐、硬件时序或电机平顺性。尚未烧录。

2026-10-09新增第四通道后：每帧4个float+帧尾，共20字节，300帧DMA块6000字节；原始备份点保持不变。

## 最新流程：前后各3秒（2026-10-09）

覆盖上文旧测试流程：M1先输出3秒启动前采样（MOE=0），再自动对齐/加速/持续运行；M0立即关断，继续3秒后采样再结束。前采样期间M0取消自动启动，后采样期间重复M0不延长计时、M1不生效。故障立即结束，不保证后采样完整。全程沿用上电偏置。
VOFA新增CH4阶段：0前采样、1对齐、2加速、3运行、4后采样。CH0..3保持电流与三相和；每帧24字节，300帧块7200字节。M0后请等待至少3.5秒保存波形，再D0回文字（提前D0会排队到采样和发送结束）。滑行期间不一定为零电流，观察后段完全停稳数据。
原备份点和回退命令不变。编译和主机状态机模拟通过，未烧录，实机前后曲线待验证。

最新M0后采样调整：正常停机只关闭功率，不打断原采样中断；MOE=0的后采样阶段检测到2A越限会锁存故障并继续记录，运行中的过流仍立即关断，ADC缺样/近轨仍终止。D0增加PostZero计数/越限/ADC快照，正常完成应samples=45000/45000、MOE=0、UIE=0。实机提前停发根因尚待日志确认。
